## Rules and denominators

* The catalog and baked snapshot enumerate **28 keys**. The full non-diagonal
  key-space is `28 × 27 = 756`. The stored `radii` array has 702 distinct
  `(inner, target)` key pairs. The 54 missing pairs all target `nephroid` or
  `three_leaf` (27 incoming directions to each); they are **missing data**,
  not zero radii.
* The manuscript generator takes the **raw discovery** `pairs` array, selects
  `not pair.get("trivial")` (560), then counts
  `confirmation.confirmed` within that subset (475),
  `symbolic_touch.status == "symbolic_verified"` (323), and the difference
  `560 - 475 = 85` as unconfirmed. It does **not** deduplicate aliases, and
  `confirmation.confirmed` is not a global sharpness certificate. The raw
  trivial flag is true on 142 rows.
* The standalone snapshot (byte-identical to the site's baked JSON) instead
  has status counts: `touch_proven_exact` 323, `closed_form_confirmed` 140,
  `trivial_containment` 142, `unidentified` 85, `audit_required` 12.
  The first two statuses sum to 463, **not** the manuscript's 475 confirmed
  discovery candidates: the 12 `audit_required` rows remain quarantined in
  the baked status taxonomy. Do not equate the two predicates or promote
  `touch_proven_exact` to a fully discharged global proof.
* The exact generator formulas for `janowski_A0_B-1` and `order_0.5` both
  simplify to `1/(1-z)`: the order-half formula is
  `(1+(1-2*(1/2))*z)/(1-z)`, the Janowski formula is
  `(1+0*z)/(1-1*z)`. This is **identity**, not just a literature synonym.
  The stored rows between these keys both have radius 1. Deduplicate only
  these proven equivalent keys for the following audit view; preserve every
  original row and source locator in public data.
* Mapping `janowski_A0_B-1 → order_0.5` yields 27 mathematical generator
  expressions in the stored key set. The 702 raw rows map to 651 canonical
  ordered cells: 650 off-diagonal and one diagonal alias-identity cell
  (two original rows). Off-diagonal status counts are 290 touch, 133
  closed-form, 133 trivial, 83 unidentified, 11 audit-required. The 650
  off-diagonal cells consist of 517 nontrivial under the source discovery
  predicate (`status != trivial_containment` for these matched rows) and
  133 trivial. The raw discovery gate on the same canonical off-diagonal
  cells yields 434 confirmed, 290 symbolic, 83 unconfirmed. These are **not**
  new certificate totals.
* The distinct-class non-diagonal universe after alias collapse is
  `27 × 26 = 702`, with 650 populated canonical directions and 52 missing
  directions (26 incoming to each of the two unpopulated target classes).
  The numerical coincidence between **702 raw stored key rows** and
  **702 possible canonical directions** does not mean the canonical atlas
  is complete.

## Unresolved publication decision

The manuscript macros accurately reproduce the *alias-inclusive discovery*
snapshot, but the prose can be read as counting 702 distinct class pairs and
560 independent nontrivial problems. A reviewed manuscript correction should
explicitly label the historical raw-key denominator, identity alias, missing
pairs, and distinction between confirmed touch equations and sharpness proofs;
if the intended claim is instead **canonical distinct-class** problems, the
macro generator, both TeX roots, tables/figures, and reviewed snapshot must be
regenerated together and reviewed before a new submission. This package audit
does not silently rewrite either manuscript root, certified DB, or deployed
site. In particular, do not replace 702 with 650 while retaining the original
560/475/323 denominators.
